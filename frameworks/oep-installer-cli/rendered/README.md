
### Introduction

This directory contains a set of commonly used finalized installers. 

| Name | Description |
|:-----|:------------|
|[openedge-cli](openedge-cli) | The full debian installer that includes all modules and profiles. No preset installation commands. |
|[openedge-cli-fedora](openedge-cli-fedora) | The full fedora installer that includes all modules and profiles. No preset installation commands. |
