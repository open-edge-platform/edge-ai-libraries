# Audio

The **Audio** page provides three American English WAV samples from the
[Open Speech Repository](https://www.voiptroubleshooter.com/open_speech/american.html).
Each recording is 16-bit PCM at 8 kHz and contains Harvard sentences.

Use **Download** on a row to download one recording, or **Download all** to
download the recordings that are not downloaded yet, one after another.
Recordings are stored on the server in `shared/audio/input/auto` and become
available as predefined input for the Speech to Text pipeline. The source requires identifying
the material as **Open Speech Repository** when it is used.
