# Dependencies required by the SLIM image variant (review point #4): the
# default OpenVINO GenAI Whisper transcription path, VSS/MinIO ingestion,
# and on-first-run OpenVINO model export (optimum-cli). This is the
# dependency floor of the service -- every package listed here is needed
# even with every optional provider/feature disabled.
#
# Excluded from this file (see requirements-optional.txt): the openai
# and whispercpp ASR provider backends, and diarization/sentiment
# (pyannote.audio, speechbrain). Those providers' classes are imported
# lazily (components/asr_component.py, components/sentiment_component.py)
# only when actually selected/enabled, so omitting their packages here
# does not break slim-image startup -- selecting an excluded provider at
# runtime fails with a clear ImportError instead (see whispercpp/whisper.py
# for the existing pattern).
#
# The FULL image installs this file AND requirements-optional.txt.
#
# Pin consistency: resolved versions for every package below are also
# constrained via requirements-lock.txt (`pip install -r ... -c
# requirements-lock.txt`), which was generated from a full-variant install
# and verified (by rebuilding) to resolve identically for this reduced set.
