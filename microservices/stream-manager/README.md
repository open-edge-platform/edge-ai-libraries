# Stream Manager

Stream Manager is a microservice responsible for managing and orchestrating streaming data within the Edge AI platform.

A reusable REST microservice that attaches live streaming sources, keeps bounded per-stream history in memory, saves requested intervals, and returns timestamp-correlated clips and frames.

## Overview

The Repo right now only contains the scaffoldings for the Stream Manager microservice.
